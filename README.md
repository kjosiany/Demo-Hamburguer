# Brasa de Vila — site institucional demonstrativo

Site one-page responsivo para uma hamburgueria de bairro.

## Como abrir
1. Extraia o projeto.
2. Abra `index.html` em um navegador moderno.
3. Para publicar, envie a pasta para sua hospedagem estática.

## Estrutura
- `index.html` — conteúdo e estrutura
- `styles.css` — identidade visual e responsividade
- `script.js` — menu mobile e filtros do cardápio
- `assets/` — fotografias fornecidas no projeto

## Observação
Este é um projeto demonstrativo. Nome, endereço, telefone, WhatsApp, Instagram, preços e horários são fictícios e devem ser substituídos pelos dados reais do cliente.

Os links de WhatsApp, telefone, Instagram, iFood e Google Maps estão configurados como exemplos.
